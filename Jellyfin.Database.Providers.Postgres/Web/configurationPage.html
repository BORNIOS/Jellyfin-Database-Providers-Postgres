Mantenimiento de la base de datos

Estas operaciones solo están disponibles cuando PostgreSQL está activo. Cada una pide confirmación y avisa del resultado con una notificación.

VACUUM ANALYZE

Recupera el espacio de filas muertas y actualiza las estadísticas del planificador. Tarda segundos y no bloquea lecturas.

REINDEX DATABASE

Reconstruye todos los índices. Puede tardar varios minutos y bloquea escrituras mientras corre.

Optimización de rendimiento

Crea índices GIN trigram (pg_trgm) para búsqueda instantánea y ajusta autovacuum en las tablas críticas. Es idempotente: se puede repetir.

Ubicación y herramientas

Carpeta que contiene pg_dump, psql, etc. Ej: C:\Program Files\PostgreSQL\17\bin  |  /usr/lib/postgresql/17/bin  |  Vacío = autodetectar.

Retención

Elimina los respaldos antiguos para que el disco no se llene. Solo toca archivos con el nombre que genera este plugin y siempre conserva los más recientes. Se aplica tras cada respaldo y en la tarea programada «PostgreSQL Backup Retention».
